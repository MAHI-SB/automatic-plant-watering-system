# 🌱 Automatic Plant Watering System using Arduino

## 📌 Project Overview

The Automatic Plant Watering System is an Arduino-based project that automatically waters plants according to the moisture level of the soil.

The system uses a soil moisture sensor to detect whether the soil is dry or wet. When the soil is dry, the water pump turns ON automatically. When the soil is sufficiently wet, the pump turns OFF.

## 🎯 Objectives

- Automatically water plants when the soil becomes dry.
- Reduce water wastage.
- Reduce the need for manual watering.
- Monitor soil moisture conditions.
- Provide a simple and low-cost irrigation solution.

## 🛠️ Components Used

- Arduino Uno
- Soil Moisture Sensor
- Relay Module
- Water Pump
- 16×2 I2C LCD Display
- Connecting Wires
- Power Supply

## ⚙️ Working

1. The soil moisture sensor detects the moisture level of the soil.
2. The sensor sends the information to the Arduino.
3. If the soil is dry, Arduino turns ON the relay.
4. The relay activates the water pump.
5. When the soil becomes wet, Arduino turns OFF the relay.
6. The LCD displays the current watering status.
